# zero7.com.br/mentor-iava/ — gerado por scripts/publicar.mjs (fonte:
# scripts/htaccess.txt). Não editar o dist/.htaccess à mão.
#
# ⚠ ATENÇÃO: a Content-Security-Policy abaixo é ESTRITA. Se entrar Google Tag Manager,
#   Pixel do Meta, Hotjar, RD Station ou QUALQUER script de terceiro, a CSP precisa ser
#   atualizada (script-src, connect-src, img-src, frame-src...), senão ele é bloqueado
#   pelo navegador — e scripts que injetam código inline (GTM) exigem nonce ou hash.
#   Teste com o console aberto: toda violação aparece como "Refused to load...".
#
# Terceiros liberados hoje (e por quê):
#   - www.youtube-nocookie.com  (frame-src): o vídeo da #demonstracao, só depois do
#     clique na capa (antes disso nada do YouTube é pedido)
#   - Meta Pixel (js/pixel.js; sem pedido de consentimento, decisão do dono), levantado
#     na Network com scripts/pixel.mjs — só o que ele usa de fato:
#       connect.facebook.net  (script-src): fbevents.js — depois da página pronta
#       www.facebook.com      (img-src):    /tr/ — os eventos (GET de imagem)
#     Com a configuração remota desligada (fbq.disableConfigLoading) e sem eventos
#     automáticos, ele não baixa signals/config nem fala com os gateways da API de
#     conversões (*.on.aws, *.run.app — que a configuração dos pixels liga): connect-src
#     segue só 'self'.
#   (o selo do Reclame Aqui saiu da página em 2026-09-22; a implementação e as
#   liberações que ele exigia estão em docs/selo-reclame-aqui.md)
# ═══════════════════════════════════════════════════════════════════════════════

Options -Indexes
DirectoryIndex index.html

<IfModule mod_mime.c>
  AddType image/avif .avif
  AddType image/webp .webp
  AddType font/woff2 .woff2
  AddType font/woff .woff
</IfModule>

# ─── segurança ───
<IfModule mod_headers.c>
  Header always set X-Content-Type-Options "nosniff"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  Header always set X-Frame-Options "SAMEORIGIN"
  Header always set Permissions-Policy "accelerometer=(), camera=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), payment=(), usb=(), browsing-topics=(), autoplay=(self \"https://www.youtube-nocookie.com\"), encrypted-media=(self \"https://www.youtube-nocookie.com\"), picture-in-picture=(self \"https://www.youtube-nocookie.com\"), fullscreen=(self \"https://www.youtube-nocookie.com\")"
  Header always set Content-Security-Policy "default-src 'self'; script-src 'self' https://connect.facebook.net; style-src 'self'; img-src 'self' data: https://www.facebook.com; font-src 'self'; connect-src 'self'; frame-src https://www.youtube-nocookie.com; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'self'"
</IfModule>

# ─── compressão (texto) ───
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/css text/javascript application/javascript image/svg+xml text/plain
</IfModule>

# ─── cache: 1 ano para arquivos versionados (?v=hash); index.html sempre revalida ───
<IfModule mod_headers.c>
  <FilesMatch "\.(css|js|woff2?|avif|webp|png|svg|ico)$">
    Header set Cache-Control "public, max-age=31536000, immutable"
  </FilesMatch>
  <FilesMatch "\.html$">
    Header set Cache-Control "no-cache"
  </FilesMatch>
</IfModule>
